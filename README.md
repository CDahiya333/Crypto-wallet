
# Crypto wallet

A feature-rich crypto wallet that provides a beautiful UI and allows users to connect to numerous mainnet and test networks. Users can perform various operations such as sending money, adding tokens, tracking transactions, and managing their accounts through a seamless authentication system.


## Features

- **Connect to Multiple Networks**: Supports various blockchain mainnets and testnets via Alchemy APIs.
- **Secure Transactions**: Send and receive cryptocurrency securely between wallets.
-- **Transaction History**: Maintain a record of recent Transactions
-- **User Authentication**: Sign up and Sign in



## Tech Stack

**Authentication**: JWT-based authenticaion
**DataBase**:MongoDB
**BlockChain API**: Alchemy-skd API
**BackEnd**:NodeJS and Express



## Installation

1. Clone the repo
2. Install Dependencies
```bash
  npm install 
```
3. Set up environment variables, project inclues a config.env file.
```bash
    MONGO_URI=your_mongodb_connection_string
    ALCHEMY_API_KEY=your_alchemy_api_key
    JWT_SECRET=your_jwt_secret_key 
```
4. Navigate to chromeapi directory
5. Start Development server
```bash
  npm start
```
